# Raw Ore Crafting

> Skip the furnace — craft raw ores straight into their finished products.

In vanilla Minecraft, raw iron, raw copper, raw gold and ancient debris have to be smelted in a furnace before they are useful.
**This mod adds crafting-table recipes for them** — one raw ore crafts directly into the finished item. No coal, no waiting, no furnace.

Supports **Forge 1.16.5** and **Forge 1.20.1**.

---

## Recipes

All recipes are **shapeless** (place the item anywhere), 1 ingredient → 1 result.

### Forge 1.20.1

| Input | Output |
| --- | --- |
| Raw Iron | Iron Ingot |
| Raw Copper | Copper Ingot |
| Raw Gold | Gold Ingot |
| Ancient Debris | Netherite Scrap |

### Forge 1.16.5

> This version predates raw ore items (raw iron/copper/gold were added in 1.17) and has no copper,
> so the corresponding ore blocks are used instead.

| Input | Output |
| --- | --- |
| Iron Ore | Iron Ingot |
| Gold Ore | Gold Ingot |
| Ancient Debris | Netherite Scrap |

## Installation

1. Install **Forge** for your game version.
2. Drop the downloaded jar into your `.minecraft/mods/` folder.
3. Launch the game — no configuration needed.

> Can't find the `mods` folder? Open your game directory from the launcher and create a `mods` folder if it isn't there.

## FAQ

**Q: Do I need it on both the client and the server?**
A: No. It works **server-side only** — vanilla clients can join without it (recipes are synced by the server).
In singleplayer, just drop it into `mods/`.

**Q: Does it remove the furnace recipes?**
A: No. It only **adds** crafting-table recipes; smelting still works as usual.

**Q: Does it affect balance?**
A: It adds a few 1:1 recipes whose outputs are exactly the same as smelting, and changes nothing else.

**Q: Are other Minecraft versions supported?**
A: Only 1.16.5 and 1.20.1 for now.

**Q: Will it conflict with other mods?**
A: Very unlikely. It only adds recipes; it does not modify any vanilla items or blocks.
