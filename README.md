# Raw Ore Crafting · 原矿直合成

> 不用熔炉，粗矿直接在工作台里合成出成品。

Minecraft 原版里，粗铁、粗铜、粗金、远古残骸这类东西必须丢进熔炉烧一遍才能用。
**这个模组给它们加上了工作台配方** —— 一个粗矿直接合成出对应的成品，省煤、省时间、省熔炉。

适配 **Forge 1.16.5** 和 **Forge 1.20.1**。

---

## 配方

全部为**无序合成**（随便摆），1 个材料 → 1 个成品。

### Forge 1.20.1

| 放入 | 得到 |
| --- | --- |
| 粗铁 | 铁锭 |
| 粗铜 | 铜锭 |
| 粗金 | 金锭 |
| 远古残骸 | 合金碎片 |

### Forge 1.16.5

> 该版本还没有「粗矿」物品（粗铁/粗铜/粗金是 1.17 才加入的），也没有铜，
> 所以用对应的矿石方块代替。

| 放入 | 得到 |
| --- | --- |
| 铁矿 | 铁锭 |
| 金矿 | 金锭 |
| 远古残骸 | 合金碎片 |

## 下载

前往本仓库的 **[Releases](../../releases)** 页面，下载与你游戏版本对应的 jar：

| 游戏版本 | 文件名 |
| --- | --- |
| 1.20.1 | `orecrafting-1.20.1-1.0.0.jar` |
| 1.16.5 | `orecrafting-1.16.5-1.0.0.jar` |

## 安装

1. 先给你的游戏装好 **对应版本的 Forge**。
2. 把下载的 jar 放进 `.minecraft/mods/` 文件夹。
3. 启动游戏即可，无需其他设置。

> 找不到 `mods` 文件夹？在启动器里打开游戏目录，没有就自己新建一个。

## 常见问题

**Q：需要客户端和服务端都装吗？**
A：不用。这个模组**只装在服务端就能生效**，没装它的原版客户端也能正常进服（配方由服务端同步）。
单人游戏的话，直接放进 `mods/` 就行。

**Q：会删掉熔炉的烧炼配方吗？**
A：不会。它只是**额外增加**工作台配方，熔炉照旧能用。

**Q：会影响平衡吗？**
A：只新增了几个 1:1 的合成，产物和烧炼完全相同，不改动其他任何内容。

**Q：支持别的 Minecraft 版本吗？**
A：目前只有 1.16.5 和 1.20.1。

**Q：会和别的模组冲突吗？**
A：几乎不会。它只往配方表里加东西，不修改原版物品或方块。
